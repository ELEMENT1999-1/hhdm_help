Event Entities

Event entities are considered to be all data entities that belong to a specific event. The views presented in this section are all available on the Event tab of the ribbon bar. To be able to view this data the user must be subscribed to the event.

There are different levels to the event-related data:

event data

event/car data

event/session data

event/car/session data

Event data is data that is related to the event, but not to a specific car. A weather measurement at an event would be considered an event data entity.

Event/car data is data that is related to the event and a specific car. A setup or a tyre set would be considered and event/car data entity.

Event/session data is data that is related to the event and a specific session, but not related to a specific car. By default there is no functionality in HH Data Management linked to this data level, but there is a SessionData entity available that can be customized using the definitions, and a custom view could be created to edit the entity if it is needed.

Event/car/session data is data that is related to the event and a specific car and session. A run sheet or a run plan would be considered and event/car/session entity.
