Tutorials

This sections provides walkthroughs for various topics in HH Data Management and is designed to complement the rest of the documentation. Some topics are better explained with an extended example and these are found here.

Initial account setup - this tutorial explains how to get started with an empty account, create a setup definition and add parameters to it, build the user interface of the setup sheet, and finally how to create an event, and populate some setup data for that event

Main graph introduction - this tutorial gives a walk through of creating a graph using the main graph, and demonstrates the application of features presented in the documentation

Event report mileage - this tutorial shows how a mileage report can be created using the event report

Brake set management - this tutorial explains how to manage brake sets with assemblies and item measurement view.

Excel export examples - this tutorial gives some examples of how to export different entities from HH Data Management.

Displaying shared images via attached files - this tutorial explains how to use attached file parameters to display a common image across multiple linked items, such as displaying a car model picture within a setup.

Using tyre set assembly to manage wheels - this tutorial explains how to use a tyre set assembly to manage wheels, rims, sensors, and follow the mileage.
