History typesâ

Assembly iteration history items can be assigned a history type such as "Service", "Inspection", or "Crash Repair". History types have a parameter "ResetsMileage" that is used when computing the "MileageSinceLastService" and "MileageHoursSinceLastService" parameters on assembly iterations. History types can be managed from the Admin tab of the ribbon bar:

tipIf the view is missing from the ribbon bar, please ensure your client permission profile includes the view "Admin.HistoryTypes".
