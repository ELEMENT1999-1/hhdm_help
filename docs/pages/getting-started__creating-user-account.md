Creating user account

After getting added to an HH Data Management account, if there is no user account already created, a user will receive a welcome email with a welcome link asking to confirm the email address. Click the link and a new browser page will open allowing a new password to be set:

The password set on this page is the password that will be used to log in to both the hh-dev.com website and HH Data Management.
