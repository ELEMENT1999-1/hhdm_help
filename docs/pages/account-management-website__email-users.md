Email Users

Restricted AccessThis section of the website is only accessible by Account Admin users

The email users feature allows an Admin Account to email to every user from their account. This can be used to communicate new releases or documentation, for example.

To send an email, specify:

Email subject

Custom reply-to address: Use if you want the user to be able to answer you directly once they receive the email (optional)

Email: Body of the email to be sent

After composing the email, make sure to click Send.
