Championships

The championships view can be accessed from the admin tab of the ribbon bar:

infoWhen New Setup For Each Run is selected, the default math parameter with the same name in the SessionCarData definition evaluates to true. This causes a new setup to be created each time a new run is created using the Copy Run button. The intention is to have a new setup for each run instead of reusing a setup until car changes are made.

infoIf Lock Mileage is selected, this championship's mileage will not recompute when a mileage recalculation is requested for the account. See the mileage page for more.

tipThe software uses a "smart" convention for the naming of the auto-generated setup. The last number in the name will be incremented by one. For example, if the selected setup name on the current run is FP1_RUN01, the auto-generated setup for the next run will be FP1_RUN02.

cautionTo be able to delete a championship, you need to make sure that no events are registered under this championship.
