Configuration Entities

Configuration entities in HH Data Management are the parts of the software that do not contain any actual data and are used to customize the software.

Definitions are used to customize the data schema of the software. They allow parameters to be created to store data throughout the software. The CID definition, CGD definition, custom columns and custom views are used to customize the user interface of the software, both the default views in the software and to create brand new views that will only be available on the current account.
