On this pageFuel calculation

The fuel calculation is used in the run sheet. Its behaviour can be customized using a plugin.

Fuel use measurements can be written automatically by the Telemetry Readers through the HH Timing DMI plugin.

See the flowchart legend section for an explanation of the flow chart symbols.

Run sheet fuel valuesâ

Start fuelâ

"Start fuel" is the amount of fuel in the tank at the start of the run.

Fuel used (SOR)â

"Fuel used (SOR)" is the total amount of fuel used since the value was last reset (either at the start of the session, or with a run sheet math parameter).
SOR stands for "Start of Run"

tipThe user may define a run sheet math parameter named 'FuelUsedSORMathParameter' to customize the behavior of the Fuel Used SOR calculation.

Fuel consumedâ

"Fuel consumed" is the amount of fuel used during the lap.

Fuel remainingâ

"Fuel remaining" the amount of fuel left in the fuel tank at the end of the lap.

Fuel usedâ

"Fuel used" is the total amount of fuel used since the value was last reset (i.e. at the start of the event, session, or run).
