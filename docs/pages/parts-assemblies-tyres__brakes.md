Brakes

dangerAlthough there are dedicated brake modules in HH Data Management, this functionality has been deprecated, and all brake related components should now be tracked using the standard part and assembly features. See the brake set management tutorial for further information on this configuration. The brake module will be removed in a future release. We will work with customers to transition any existing data to the new representation so no data will be lost.
